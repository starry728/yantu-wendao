# 研途问道 · 研究生修仙录

这是我用 **豆包（Doubao）** 从零做的**第一个网页游戏**，也是一次用 AI agent 做创造性工作的完整实践：把研究生生活玩成一场修仙养成——接学习任务涨修为、五行灵根、境界突破、灵田种药、就业常识答题、多角色图鉴。

## 快速开始

1. 下载或克隆本仓库；
2. 直接用浏览器打开 `研途问道.html` 即可游玩；
3. 请保持 `assets/` 文件夹与 HTML 在同一目录（图片、视频、语音都在里面）。

> 纯前端单文件游戏，无需联网、无需安装任何依赖。

## 玩法特色

- **修仙式养成**：代码打怪、背雅思单词、写英文日记、文献精读、冥想静心、算法排错，完成任务获得修为。
- **境界突破**：炼气 → 筑基 → 金丹 → 元婴 → 化神，主角随境界进化为三种形态，突破有专属动画。
- **灵根与属性**：五行灵根，神识 / 身法 / 气血 / 灵力 / 悟性 / 气运多维属性，法器可炼器升级。
- **灵田炼丹**：山顶灵田每日浇水，灵草成熟收获后入炉炼丹。
- **就业常识答题**：社会 / 经济 / 金融 / 政治四类知识点，名词卡 + 情景题，边玩边为求职做准备。
- **同门图鉴**：多位性格各异的原创角色，部分角色带不同声线语音。

## 技术说明

- 单个 HTML + 原生 JavaScript（无框架、无构建），CSS 与 JS 均内联。
- 从策划、美术、视频、语音到编码，均由**豆包（Doubao）agent 协助完成**，是我用豆包做的第一个游戏。
- 角色为借鉴经典国漫气质的**原创角色**，美术、视频、语音均为原创生成，不含任何受版权保护的正片片段或原声，可放心公开。
